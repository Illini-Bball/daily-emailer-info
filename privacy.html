Illini Daily Player Reports

Privacy policy

Effective October 21, 2026.

Access and purpose

The account owner grants Gmail read-only access. Although this permission technically allows reading mailbox messages, this application searches for Noah basketball report emails from the configured sender, then reads matching message metadata and PDF attachments. The information is used to extract shooting statistics and charts for authorized player reports. The application does not modify, delete, or send Gmail messages.

Processing and sharing

Selected attachments and derived statistics are processed in private GitHub Actions jobs. Credentials are held in encrypted GitHub settings; persistent report state and archived run outputs are encrypted. Derived player reports are sent through Resend to the operator's configured staff recipient list. Gmail information is not sold, used for advertising, or used to train general-purpose AI models. Mailbox access is not delegated to report recipients.

Illini Daily Player Reports' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Temporary job files exist on the GitHub runner during processing. Encrypted report-run artifacts are configured to expire after seven days. Encrypted source history, derived reporting records, and delivery records may remain in the private repository state for ongoing reporting until the operator removes them. Emails already delivered are subject to the recipients' retention practices.

The account owner can revoke Gmail access in Google Account connections. Revocation stops future Gmail access but does not automatically remove previously generated reports. Contact the operator to request removal of retained application data or stop report distribution.

Contact

Contact the operator through the project support page to arrange a private discussion. Do not post mailbox contents, player records, or credentials publicly.
