Illini Daily Player Reports

A private reporting tool that combines authorized basketball practice statistics, workload records, Noah shooting reports, and game statistics into daily player reports for the configured coaching staff.

The tool runs in a private GitHub Actions repository. The account owner authorizes read-only Gmail access to retrieve Noah shooting-report PDF attachments. It does not send, delete, or modify messages in Gmail. Report delivery uses the separately configured email provider.

This website contains only application information. It provides no access to player reports, mailbox contents, or credentials. The application is operated for a limited, authorized staff workflow and is not offered as a public mailbox service.
